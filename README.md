### Projects

**[chronos-billing-engine](https://github.com/Rajekevin/chronos-billing-engine)** — usage-based billing API
Event ingestion and invoicing API in PHP 8.4 / Symfony 8. Hexagonal architecture,
asynchronous processing with Messenger, idempotency so an event is never billed
twice, API key auth and rate limiting.

**[money-tracker](https://github.com/Rajekevin/money-tracker)** — personal finance app
Symfony API + Vue 3 SPA on PostgreSQL, layered Domain / Application / Infrastructure,
fully containerized with Docker.

**[train-departures-idf](https://github.com/Rajekevin/train-departures-idf)** — real-time departure board
PWA showing the next departures for an Île-de-France Mobilités stop (PRIM API),
styled like a station display. TanStack Start, React, Tailwind.

**[jenkins-php-deployment](https://github.com/Rajekevin/jenkins-php-deployment)** — CI/CD reference
Jenkins pipeline for a PHP application: clone, checks, deploy, in Docker.

**[DevFeed](https://github.com/Rajekevin/DevFeed)** — tech news browser extension
New-tab RSS/Atom reader with categories, read/unread, favorites and themes. Vanilla JS.
